个人专属飞书 Bot 凭据绑定

配置您在飞书开放平台创建的自建应用，其他人可通过飞书向您的专属 Bot 提问。通过飞书长连接实时接收事件，无需公网地址或反向代理。凭据采用 AES-GCM 安全加密存储。
飞书自建应用长连接配置步骤指南
  1. 创建自建应用：访问 飞书开放平台 (open.feishu.cn)，点击「创建自建应用」。
  2. 添加机器人能力：在应用详情页点击「添加应用能力」-「机器人」，开启机器人能力。
  3. 配置权限范围：在「开发配置」-「权限管理」中添加以下权限：
    • im:message (获取与发送单聊、群消息)
    • im:message.p2p_msg:readonly (读取用户发给机器人的单聊消息)
    • im:message:send_as_bot (以应用身份发送消息)
  4. 添加事件订阅：在「开发配置」-「事件与回调」中添加事件 im.message.receive_v1 (接收消息 v2.0)。
  5. 切换长连接模式：在「事件与回调」模式中选择「使用长连接接收事件 (WebSocket)」。
    重要操作顺序提示：部分飞书租户配置要求客户端必须先发起长连接握手，飞书控制台才允许保存长连接模式。请先在下方填入 App ID & App Secret 并点击「保存飞书配置」，等待上方状态变为「已连接」后，再去飞书控制台保存长连接模式！
  6. 发布应用版本：在「应用发布」-「版本管理与发布」中创建并发布版本，企业管理员免审或审核通过后，团队成员即可在飞书向该 Bot 提问。
